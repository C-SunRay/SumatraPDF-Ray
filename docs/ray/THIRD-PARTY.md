# 第三方代码与许可

本项目保留 SumatraPDF / SumatraPDF-Plus 的源码历史、版权声明及 AUTHORS。

- 主项目：根目录 COPYING（GPLv3）。
- MuPDF：mupdf/COPYING（AGPLv3）。
- 部分 BSD 代码：COPYING.BSD。
- 其他依赖：ext、fonts、packages、mupdf 等目录中的 COPYRIGHT、COPYING、LICENSE 和 NOTICE 文件。
- Mermaid 的 Rust 依赖及固定版本见 ext/mermaid/Cargo.toml 和 Cargo.lock。

发布包附带主要许可文本；各组件完整许可与对应源码保存在同一发行标签的源码归档中。各组件的原始许可文件优先于本摘要。

AI/API 服务由使用者自行配置，其商标与服务条款归各服务商所有；本项目不附带服务商账户或 API 密钥。
